# Apps Built for Linux

A collection of simple, practical applications built for Linux desktops.

This repository is a home for small utilities designed to make everyday desktop tasks a little easier. Some are vibe-coded, some are built from scratch, and all are created with a focus on simplicity and usefulness.

The goal isn't to build a huge suite of applications. It's to create lightweight tools that solve small, everyday problems without unnecessary complexity.

## Philosophy

- **Simple:** Focus on doing a few things well.
- **Practical:** Solve everyday problems rather than introduce unnecessary features.
- **Linux-first:** Built with Linux desktop environments and workflows in mind.
- **Lightweight:** Keep applications straightforward and avoid unnecessary overhead.
- **Open source:** Share the code so others can explore, use, modify, and contribute.
